# 公开演示数据

`questions.json` 包含 8 道新编写的软件工程基础示例：5 道单选、3 道多选。题目、答案和解析仅用于展示答题流程，不是原课程题库，不含真实用户信息。题目 ID 使用 `demo-` 前缀，题库版本为 `demo-questions-v1`。

每题使用以下字段：

- `id`、`chapter`、`number`：题目身份、章节及序号。
- `type`：`single` 或 `multi`。
- `question`、`options`：题干及包含 `label`、`text` 的选项数组。
- `answer`、`gradable`：答案字母字符串及是否评分，例如 `A`、`ABC`。
- `explanation`、`analysis` 等：兼容历史页面的解析展示字段。

`historical-metrics.json` 仅包含此前归档审计得到的 **2868 个注册账户**和 **849292 条答题记录**两个累计指标，不含账号、学号、姓名、IP 或逐条作答。不能使用演示题库重建历史记录，也不能从这些总数推断并发量或当前活跃人数。

原课程题库的转载授权尚未确认，本次不上传；历史用户数据库、备份、迁移明细及日志也不上传。演示数据库在本地启动时新建，已被 Git 忽略。
