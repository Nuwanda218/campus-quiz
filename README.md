# 校园在线刷题与复习系统

面向校内期末复习的在线答题网站，支持在线答题、轮次进度记录和错题专项训练，使用 Python、Flask、SQLite 和 JavaScript 实现。

这是一个合作项目，本人参与开发。本仓库用于整理项目介绍及后续可公开的代码，不代表全部功能由本人独立完成；具体分工将在整理协作记录后补充。

## 主要功能

- **在线答题与进度记录**：按轮次组织答题，保存作答进度与历史记录。
- **错题专项训练**：分别保存正式答题与专项练习数据，避免练习覆盖正式轮次的进度。
- **重复提交处理**：通过提交标识识别重复作答提交。
- **题库更新**：结合数据库备份、历史题目归档与事务迁移，保留可沿用的答题进度和历史记录。
- **部署与维护**：配套部署、备份和升级脚本，支持网站运行维护。

## 历史使用记录

历史归档数据库记录 **2868 个注册账户**、**849292 条答题记录（约 84.9 万条）**。

以上为历史累计数据，不代表独立自然人数、同时在线人数、并发量或 HTTP 请求量，也不代表网站当前仍在运行。
